Beads

Beads projects

Paste the path of any folder inside a beads project (one with a .beads directory). The name defaults to the project's issue prefix.

    Get started

    1. Pick a repo that uses beads. It has a .beads folder at its root. If it doesn't yet, run bd init in it first.
    2. Paste its path in the box above, e.g. ~/code/my-repo. Any folder inside the repo works. To copy it, run pwd in one of the repo's terminals.
    3. Click Add project. It's named after the repo's issue prefix unless you type a name. Add as many projects as you like and switch between them with the menu at the top. The sidebar panel shows them all.
